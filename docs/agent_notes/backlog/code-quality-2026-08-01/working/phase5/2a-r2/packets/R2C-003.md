## Settled direction (implement this; do not re-open it)

## Problem statement from the promotion candidate

URL.pathname is not a filesystem-path conversion: it retains percent encoding for characters such as spaces and yields URL-shaped drive paths on Windows. Because this value anchors every slow-test project, affected checkouts cannot locate their package roots.
