## Settled direction (implement this; do not re-open it)

Rename the fog and drawing callback chains from toggle terminology to enable terminology, preserving their no-layer guards and create-only behavior.

## Problem statement from the promotion candidate

Public callback names promise reversible toggle semantics while the operations only create layers. Current UI guards prevent misuse, but the contract propagated through hooks and toolbar props invites later callers to assume disabling behavior.

## Verified evidence (existence-checked at step 1b)

- `packages/client/src/components/campaign/maps/map-fog-actions.ts:28-41` — FogActions exposes handleToggleFog, but its implementation unconditionally creates a fog layer.

- `packages/client/src/components/campaign/maps/map-toolbar-fog-tools.tsx:22-34` — The fog callback is rendered only when no layer exists and is labeled Enable.
- `packages/client/src/components/campaign/maps/map-toolbar-drawing-tools.tsx:47-60` — The drawing callback is likewise available only when no layer exists and is labeled Enable.
