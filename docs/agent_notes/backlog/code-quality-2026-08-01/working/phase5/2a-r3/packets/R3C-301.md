## Settled direction (implement this; do not re-open it)

Convert the notification client to a cursor-backed infinite query and add a guarded load-more/history affordance. Preserve socket prepends and optimistic mark-read updates across loaded pages, with focused multi-page and socket-prepend coverage.

## Problem statement from the promotion candidate

The persistence and wire layers implement notification history, but the only client fetch stops after 20 rows and discards nextCursor. After enough notifications accumulate, unreadCount can include rows the user cannot inspect or mark individually, and without a retention policy the inaccessible tail only grows.
