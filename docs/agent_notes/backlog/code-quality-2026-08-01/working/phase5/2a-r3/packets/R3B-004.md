## Problem statement from the promotion candidate

Three character-creation choice-chip implementations maintain selected, disabled, focus, and click semantics separately. They have already diverged: spell choices communicate pressed state, but class-skill and language choices communicate it only visually. Screen-reader users cannot determine which skills or languages are selected, and interaction changes require synchronized edits.
